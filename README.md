# MyPeople — Contact Book Desktop Application

MyPeople is a desktop Contact Book application built with **Python and Tkinter**.  
It provides a simple graphical interface for managing personal contact information locally.

## Features

- Add contacts
- Search contacts
- View contact details
- Edit contacts
- Delete contacts
- Store contact information locally
- Light and dark mode
- Scrollable contact list
- JSON-based data storage
- Windows `.exe` version available

### Contact Information

Each contact can contain:

- Name
- Phone number
- Email
- Address
- Company
- Job
- Birthdate
- Tags
- Notes
